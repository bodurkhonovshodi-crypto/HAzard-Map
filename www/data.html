Put new data into the app

Quick look: on the Map page, open the Layers tab and choose a GeoJSON, KML or CSV file. To keep it in the app for everyone:

Boundaries, roads, population (GeoJSON)

  1. In QGIS, clip the layer to GBAO and save it as GeoJSON in EPSG:4326.
  2. Run the tool below.
  3. Add the new file name to js/data-files.js.
python tools/geojson_to_js.py gbao_districts.geojson data/layer_gbao_districts.js --title "GBAO districts" --color "#5b4a8a"

NDVI, DEM, population grids (rasters)

  1. Clip the raster to your area and export it as a PNG image in QGIS (Project → Import/Export → Export Map to Image), or use the slope tool for a DEM.
  2. Read the corner coordinates and use tools/image_bounds.py to make a map layer.
python tools/dem_to_slope.py my_dem.asc data/overlays/slope_x.png --utm-zone 42 --id slope-x --title "Slope, my area" --js data/overlay_slope_x.js

New hazard sites

  • Excel tabletools/excel_to_js.py (avalanche database layout)
  • Shapefile pointstools/shp_to_js.py
  • KML points or polygonstools/kml_to_js.py
  • Damaged houses liststools/damage_lists_to_js.py

Then add the new file to js/data-files.js. The README has the exact commands.
